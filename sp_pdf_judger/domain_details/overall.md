# 목적

모든 회사와 모든 제품에 공통으로 적용하는 누락 방지 체크리스트다. 회사 및 제품 디테일은 이 문서에 추가로 적용한다.

# 근거 우선순위

1. 현재 제출된 SP 문서의 명시적 시험기준과 시험결과
2. 현재 문서와 연결된 허가서 및 공인 기준 문서
3. 코드에 구현된 결정적 비교 규칙
4. RAG 검색 근거
5. 전체·회사·제품 디테일

하위 근거로 상위 근거의 명시적 값이나 결과를 덮어쓰지 않는다. 문서에 없는 수치, 날짜, 제조번호, 판정을 추정해 만들지 않는다.

# 공통 검수 항목

## 시험기준과 시험결과

- 시험명, 시험방법, 시험기준, 시험결과가 같은 행과 같은 시험을 가리키는지 확인한다.
- 수치 기준은 단위와 비교 연산자(이상, 이하, 초과, 미만)를 함께 비교한다.
- 범위 기준은 하한과 상한 및 경계 포함 여부를 확인한다.
- 정성 기준은 의미가 같은 표현인지 확인한다. 예: 불검출, 미검출, 음성.
- 복수 조건은 조건별로 나누어 모두 충족하는지 확인한다.
- 서로 다른 용기 규격, 농도, 시험법의 기준이 함께 있을 때 현재 제품에 해당하는 기준만 선택한다.
- 기준값이 외부 문서에만 있고 현재 연결 근거가 없으면 임의 판정하지 않고 보류 사유를 명시한다.

## 문서 구조와 추적성

- 목차 번호, 시험명, 페이지, 표의 행·열 연결이 일관적인지 확인한다.
- OCR로 행과 열이 뒤집히거나 병합된 표는 시험명과 결과의 대응 관계를 재확인한다.
- 같은 시험이나 같은 제조단계가 중복 집계되지 않도록 한다.
- 판정 이유에는 사용한 기준과 결과가 무엇인지 추적 가능하게 남긴다.
- 페이지 번호가 누락되어 있지 않은지 잘 검증한다.

## 제조정보 정합성

- 제조요약도의 제조번호, 제조년월일, 제조량을 해당 제조단계의 본문 정보와 비교한다.
- 제조량과 사용량·분량·투입량을 구분한다. 사용량이나 분량은 제조량 비교값으로 사용하지 않는다.
- 기준 문서에 제조량이 없으면 제조량 미기재 사실은 표시하되, 그 사실만으로 불합격 또는 보류를 만들지 않는다.
- 제조단계의 선후관계가 시간 순서와 일치하는지 확인한다.
- 병렬 공정이 합류하는 경우 각 분기 내부 순서와 합류 이후 공통 순서를 모두 확인한다.
- 완제의약품의 제조년월일을 분병일자, 시험일자, 포장일자 등 다른 날짜로 대체하지 않는다.

## 참고 문서

- 약전, 생물학적제제 기준 및 시험방법, 허가서 등은 현재 시험과 연결되는 조항만 사용한다.
- 참고 문서의 일반 설명보다 현재 제품의 명시적 허가 기준이 우선한다.
- 근거가 서로 충돌하면 충돌을 숨기지 말고 상위 근거를 우선한 이유를 남긴다.

# 보류 원칙

시험기준 또는 시험결과가 비어 있거나, OCR 손상으로 대응 관계를 신뢰할 수 없거나, 필요한 외부 기준이 연결되지 않은 경우에만 보류한다. 직접 비교 가능한 기준과 결과가 있으면 가능한 한 충족 또는 불충족으로 판정한다.
